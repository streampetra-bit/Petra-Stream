# Petra Stream - MVP Scaffold

This starter scaffold sets up the Petra Stream MVP (Somnia Chain).

**Structure**
- `contracts/` — Hardhat Solidity contracts (StreamerRegistry, PaymentVault)
- `backend/` — NestJS backend API (stream and event handler)
- `frontend/` — Next.js + React frontend with wallet connection

**Instructions**
1. Copy files to your repo.
2. Run `npm install` (or `pnpm i` / `yarn`) in each subproject.
3. Configure `.env` (RPC URLs, private key, DB URL).
4. Deploy contracts → integrate with backend → connect frontend.
